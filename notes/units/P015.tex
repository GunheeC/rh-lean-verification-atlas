\paragraph{Hosts and connected families.} An exponent-$\lambda$ window set contains $[Y,Y^\lambda]$ at arbitrarily large $Y$. A requirement $G$ is a predicate on a scale, a frame, its host, the finite test set and the rank parameter. \code{HostExW}$(\lambda,G)$ supplies for every $0<\varepsilon<1/52$ common size constants, an exponent-$\lambda$ window set, $J\ge1$ and a threshold. Each eligible scale in that set past the threshold has ranks, a host and an auxiliary prime satisfying the size predicates and $G$. The family class $\operatorname{cls}(G,\lambda)$ requires those windows and eventual satisfaction of $G$ by every indexed member. For a primitive $\psi$, $G_\psi$ combines the host condition \code{EAtH} for the cyclic level of $\psi$ (constant $4$) and the Selmer bound \code{VVle}$(E,t,\sqrt b)$. The family assertion \code{HypV} demands the latter eventually. The predicate \code{TopG} asserts that for all $\lambda>1$ and all requirements $G$, \code{HostExW}$(\lambda,G)$ and \code{HypV} on each family of the class imply its connectedness. This gives common real $e_D,e_L$ and $\varepsilon_1>0$, followed for each $0<\varepsilon<\varepsilon_1$ by a family and constants making the chain tied on all sufficiently large window scales (\nolinkurl{CharacterBoxes/ZeroFreeAllOfTopG.lean:12--26}, \nolinkurl{ThinScalesIffHostBound.lean:120}).

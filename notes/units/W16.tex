\begin{formalstatement}[Finiteness of the candidates in a base-change frame]\label{sub:W16}
Fix a local parameter reading rule, an everywhere finite-unramified CM
extension $E/E^+$, $n\ge1$, an automorphic $\pi$ on the unitary group,
a finite set $S$ and a comparison frame for $(\pi,S)$. Choose local test
data and an auxiliary finite set $T'$ of nonsplit places disjoint from
the frame's initial set $S_0$ and its bad set. For each partition
index $i$ and each $w\in T'$, the ordered pairs of joint Hecke
eigenvalue tuples of all candidate pairs lie in a finite set. For
each $w\in S_0$ a finite list of model products suffices. Every candidate
product has the same irreducible subquotients and the same dimension
of $K'_w$-invariants as one on the list, whose invariant space is
finite-dimensional. A single integer bounds, over all candidates and
all $w\in T'$, the dimension of the candidate pair's invariants under
the prescribed two-block subgroup $I_2$.
\end{formalstatement}\subnode{W16}

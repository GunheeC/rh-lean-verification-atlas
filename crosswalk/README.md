The three name indexes scan all 1,011 registered Lean names. They cover text, TeX, Markdown, Lean, JSON, diagram sources and the other formats listed in the index. They exclude binary renderings, software implementations and CI files. A name match supplies a locator and carries no mathematical grade. Each occurrence has a file, line and Git blob identifier. With local copies of the pinned archives and Git trees, run `python3 scripts/build_name_crosswalk.py --cache DIRECTORY --check`.

# Source lines cited by field

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

A cited line locates a written step in the pinned Lean source and by itself establishes neither a line-by-line check nor a complete proof.

Each field includes units whose primary subject is that field. Within a row, count each physical line once, even when several notes cite it. The core column uses the pinned declaration weights. The raw-file column counts only citations in the original 855 complete source files. A line can occur in several fields, so adding field totals can count it twice.

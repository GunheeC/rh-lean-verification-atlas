1. Extract a declaration and check its hash

Look up the qualified name, source file and inclusive line range in the pin ledger. For the public zeta export the source is Main.lean:4–4 at commit 40e56bab026552e089d7afcfeff08d2defb9c005. Python indexes the first line as zero. Slice from line0 - 1 up to the exclusive Python endpoint line1. Joining with LF puts one newline between neighboring source lines and none at the end. Run the following command in the atlas directory.

python3 - <<'PY'
import hashlib, json, os
from pathlib import Path
pin = json.loads(Path('data/pins.json').read_text())['anchors']['riemannHypothesis']
source = Path(os.environ['LEAN_SRC']) / pin['file']
lines = source.read_text(encoding='utf-8').splitlines()
span = '\n'.join(lines[pin['line0'] - 1 : pin['line1']])
digest = hashlib.sha256(span.encode('utf-8')).hexdigest()
assert digest == pin['sha256']
print(span, digest, sep='\n')
PY

The command printed the declaration and 71b3d50605ddda7c0c74fbbf5cca47165a4cfa2ad72f50f36b907ecac7ff505a. A terminal newline in this one-line input would yield a different digest. 3. Recompute dominated lines for one node

In the graph rooted at allChi, a declaration $v$ dominates a reached declaration $w$ if every directed path from the root to $w$ contains $v$. Delete $v$, traverse again and subtract the surviving weight. A supplier with an alternative path survives, even if it lies below $v$ in the original traversal.

For a concrete example take the row-to-half-plane declaration in P011. The atlas records the fingerprint and declaration-name index in progress/position_graph.json. Follow the graph regeneration procedure to reconstruct the traversal arrays outside the atlas. The deletion program verifies the resulting bytes before traversing. The arrays retain every vertex, its weight and every distinct outgoing dependency, except that nodes tagged lit have no outgoing edges. This stopping convention defines its literature frontier. The tag says where traversal stops; it establishes no equivalence with a published result. Each reachable core declaration with a valid source span contributes its inclusive line count exactly once. This choice counts overlapping spans of different declarations independently.

The reconstructed arrays omit duplicate edges and retain all vertex weights. The packer checks their fingerprint against the published index. The graph includes dependencies arising in types, values and constructor data. Its weight describes reachability for this root and this frontier. A high weight can belong to a two-line theorem that gathers many suppliers. Adding parent and child weights double-counts their shared dominated region.

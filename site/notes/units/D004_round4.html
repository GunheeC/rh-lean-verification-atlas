A fixed local Wach datum, its Fontaine data and a compatible comparison determine a whole collection of lattice and cohomological assertions. This unit gathers them on the same input so later estimates can select the clauses they need. GlobalTheory.T.wachLattice_laterClauses_hold (WachLatticeLaterClausesHoldStatement.lean:8–9).

Write the dependent inputs in order

Fix the host $D$, then Wach data $HW$ for its local theory, Fontaine data $F$ for that particular $HW$, and finally comparison data $C_m$ for all three. The conclusion is a nested conjunction. It contains global freeness, predicates P2 through P9, a characterization of the Wach lattice, a semisimple quotient condition, Pr2a through Pr2d, a third lemma and Conclusion E. The comparison datum occurs in the types of particular conjuncts. Erasing it globally because some clauses do not mention it would change the question. The local family applications, including T25, need propositions about a single compatible choice. GlobalTheory.T.wachLattice_laterClauses_hold (WachLatticeLaterClausesHoldStatement.lean:8–9). Trace the Wach block

Unfolding the conjunction in order gives a useful checklist. The freeness witness uses $D,HW,F$. The trivial-mod-uniformizer and crystalline-comparison suppliers take $C_m$ as well. For the next group the source calls the low-level expansion, height from Hodge jumps, saturated exactness, cocycle-pole, P8 and tame-descent theorems. Compare the actual arguments at each call. For example, the P8 supplier takes comparison data even though the P8 predicate in the assembled conjunction has no explicit comparison argument. The distinction is between what the result states and what its constructor needs. GlobalTheory.NL.wach_used_clauses (WachLatticeLaterClausesHold.lean:28–38). Trace the cohomology block and the last pair

After the characterization and the semisimple quotient, the constructors use the Herr first-cohomology description, the finite-condition restriction test, the finite cocycle-class result, and a second-cohomology torsion kernel. The next component is the crystalline-surjection cokernel killed by a power of the lattice variable. Finally the source opens Conclusion E and pairs a Nygaard-extension statement with the local-comparison result. This last use again takes the same $C_m$. The assembly itself consists of placing these proofs into their corresponding fields; each individual bound or exactness statement retains its own proof obligation. For comparison with another local use of these data see D006. GlobalTheory.NL.wach_used_clauses (WachLatticeLaterClausesHold.lean:28–38).

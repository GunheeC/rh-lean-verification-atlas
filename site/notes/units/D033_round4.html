Outlined · pending_review. The convergent unitary Siegel–Weil input supplies a uniform bound on the contribution from nonzero nongeneric terms in the same row for tied two-word data. Its constants are chosen before the row and test data, so later row estimates can use the same error scale.

Statement and hypotheses

The convergent unitary Siegel–Weil input supplies a common nonnegative row-error constant and two largeness thresholds for each set of admissible parameters. Every tied, standard two-word datum satisfying Hyp0 and absolute convergence has the required bound for the normalized sum of real inner products over pairs of nonzero nongeneric terms in the same row with $s_0=1$ with that error scale.

$$\mathrm{SiegelWeilUnitaryConvergent}\ \Longrightarrow\ \mathrm{RowNGP}.$$

Identify the nongeneric pairs

Let $Q$ consist of pairs $(t,t')$ with nonzero $G$ on both terms, both terms nongeneric, equal rows and $s_0(t,t')=1$. The estimated quantity is $\Gamma_1\sum_{(t,t')\in Q}\operatorname{Re}\langle v_t,v_{t'}\rangle$. The pair definition imposes no distinctness requirement. Write down the order of choice

Fix the external row parameters subject to the stated size assumptions. The row assertion supplies a nonnegative error constant and two thresholds. They precede the free scale choices, datum, the two words and the concrete row tests. Standardness, the local row hypotheses and absolute convergence restrict the tests to which the estimate applies. In particular, one cannot choose a convenient error bound from an individual row and then reuse it for another one. The cited definition is the place to compare these quantifiers to the uniform theorem used below. RowNGP · RowsPos.lean:37-41 · rowNGP_of_siegelWeil · RowPositivityOfSiegelWeil.lean:10-15

Use the pinned bound on those choices

Apply the closed corank-one nongeneric row bound to the Siegel–Weil data, the uniform step-choice input and the two fields giving the pin and the nongeneric form. Its remaining hypothesis asks for uniform constants in the pinned analytic theorem. Specialize that theorem to the external parameters, obtaining the error constant and thresholds together with their bound. Return these same constants, then pass all the subsequently supplied datum and word variables to the bound.

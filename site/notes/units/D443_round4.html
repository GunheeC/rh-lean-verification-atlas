Put the global assertion at the chosen good cover

Fix the size and host data, the selected point $p$, the index $i$ and its good cover $Y$. The deep-law theorem uses the range condition for the shifted index $i+1$ together with the relevant component of goodness for $Y$. This gives the laws on $Y.U$ for the fixed parameter $\xi_R(D)$. The log-period theorem then produces a character and the equality identifying its period with that of the actual host. The proof must use the same character and its host conditions when specializing the global statement. Replacing it by a character with matching local degree only would leave the period identity unaccounted for. GlobalTheory.CovTop.FlatDegProof.flatDegAt_of_st (DivisorProofs/FlatDegreeStatement.lean:15–23).

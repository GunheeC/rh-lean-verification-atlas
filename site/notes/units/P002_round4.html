The public zeta export spells out the exclusions on a zero and passes the resulting predicate to the same supplier used for the Mathlib formulation. The exclusions matter when the argument reflects a zero across the critical line. riemannZeta_eq_zero_re (Main.lean:6–6).

Read the binders before the alias

Take any complex number $s$. The first premise is the equality $\zeta(s)=0$. The second denies the existence of a natural number $n$ for which $s=-2(n+1)$, so it starts with $-2$. The last premise is $s\ne1$. The output is an equality of real numbers. The public source passes a term of type RiemannHypothesis directly across this boundary. P001 is the parallel export with the Mathlib name. A comparison which checked the real-part equation alone could miss the entire exclusion at the negative even integers. RiemannZetaZerosOnLine (Statements.lean:3–4). riemannZeta_eq_zero_re (Main.lean:6–6).

Identify the input used at modulus one

The actual supplier is P008. Given the all-character assertion P009, its proof fixes the character of modulus one. The hypothesis there admits either a nonprincipal character or an argument different from one. Only the latter choice applies. Rewriting the modulus-one L-function gives zeta nonvanishing on the required right half-plane with the same excluded point. rhOfAll (MainTheorems.lean:9–9). Formalism.VW.rh_of_every (CritLine.lean:29–32).

Inspect the difficult case of the reduction

A zero to the right gives an immediate contradiction. For a zero to the left put $t=1-s$. The special value at zero gives $s\ne0$, so $t\ne1$, and its positive real part allows the gamma-factor calculation. A zero of the cosine factor would give $s=-2k$ with $k$ integral. Negative $k$ conflicts with the assumed real part, $k=0$ is already excluded by the special value, and positive $k$ supplies the natural witness $k-1$. Thus each factor in the functional equation at $t$ is nonzero. This is the place to compare the explicit quantifier with the value used in the analytic reduction. Reading the one-line public alias covers none of the arithmetic behind P009. Formalism.VW.rh_of_right (RhOfRight.lean:5–62).

Reproduce the export check

Run from the atlas checkout. Set ALPOGE_RH_SRC to the absolute path of the src directory of a separately obtained Lean checkout at the commit in sources. The following command was executed on 25 November 2026. It compares the full inclusive source span to the atlas digest, then tests the specific supplier or projection used by this export.

from pathlib import Path
from hashlib import sha256

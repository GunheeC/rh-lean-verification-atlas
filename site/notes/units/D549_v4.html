D549 · Bounding the discarded character sum

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

The pinned source paths below use the root src/. The proof is adapted from the project’s manuscript v4 and is pending_review. Manuscript v4, §3.1, printed pp. 16–17. Unit card · Mathematical editions.

Assume a fixed host satisfying its frame axioms, $x>0$, the explicit-formula datum $\mathrm{EAtH}(\Lambda,H,TT,x,\varepsilon,C_E)$, and a logarithmic-derivative function $\ell$ compatible with the matched primitive characters. Here $TT$ is the set of selected places and $n_T=|TT|$.

Put $E_0=(\mathbb Z/2)^2$, $s_0=((1,0),0)$, $e_1(t)=s_0+(0,t)$ and $\mathcal A=\{\xi\in\widehat{E_0\times H}:\xi(0,A_0)=1\}$. The character sum at $y$ is denoted by $G_\xi(y)$. Write $K'$ for the kept subset, $o=\Lambda.o$, $c=(3o+1)^{-1}$, $M=4o$, $K_o=\sum_{\psi\in\Lambda.\mathrm{KEPT}}|(L'/L)(1,\psi)|$ with the stated convention for the logarithmic derivative at one.

The discarded error is $\Sigma_A(x)=\sum_{\xi\in\mathcal A\setminus K'} |G_\xi(x)|$. A frequency outside the kept set is nonprincipal, since the principal primitive character is kept. Its value at the involution is one of the two signs. A positive sign outside the kept set and a negative sign each put it in the bounded pool supplied by the same host. The matching of its prime-power values, including inertia at ramified primes, gives $G_\xi=g_{p_\xi}$. The band consists of characters of $E_0\times(H/A_0)$, so has $4o$ members. Character dictionary · Band and both sign cases.

The pointwise bound clause on precisely the same bounded set gives $|G_\xi(x)|=|g_{p_\xi}(x)|\le x^{1/2+\varepsilon}$. Adding this for $\xi\in\mathcal A\setminus K'$ yields $\Sigma_A(x)\le |\mathcal A\setminus K'|x^{1/2+\varepsilon} \le4o\,x^{1/2+\varepsilon}$ since $x>0$. This proves D549 (sigA_le, PrimitiveCosets/SigALe.lean:18–60).

Point for the reviewer

The pointwise host bound applies only after the omitted frequencies have been identified with the designated bounded class; check both signs.

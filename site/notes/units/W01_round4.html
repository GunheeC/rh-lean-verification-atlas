Assemble one rank record

  1. Supply the CM field of the record. Starting with $O$, form the eleven components required by the CM hypothesis. In particular the dual-crystal assertion combines a dual-abelian-scheme result with a smooth-lift comparison. The elliptic CM, Hilbert class field, Deligne–Ribet, partial zeta and Hecke–Tate assertions occupy separate slots. What the assembly has to preserve

Consider a single test of the output: fix a primitive character, an allowed exponent and a page function before choosing an outer scale and its prime pair. The test allows its field to vary with a point $x$ of the returned interval and allows a new finite set of primes for every evaluation. Consequently a hypothetical argument that only returned an interval separately for each cohomological datum would leave a logical gap even if the same numerical upper bound occurred each time. In the source the same four-count implication supplies the quantified VWin as a whole. The proof of its last passage chooses the window before the field and the local data.

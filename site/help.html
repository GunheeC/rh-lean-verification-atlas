Using the local edition

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

Open site/index.html with a browser. The reading pages, diagrams, declaration search, page images and linked local evidence are available from disk. Formula typesetting uses a pinned MathJax release when the browser can reach its CDN. Offline, the original TeX remains readable.

Rebuild

From the atlas directory, run python3 scripts/build_site.py. Use python3 scripts/build_site.py --check to check that the edition matches the source files. The builder uses the Python standard library.

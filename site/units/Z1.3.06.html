Z1.3.06 · Compatibility of the local and global cocycles

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

Given a global tuple and a local conclusion valid for each tuple obeying the same pin condition, the resulting tame unramified system has a nonzero inertia value for its own cocycle. This is the compatibility step joining the two existence arguments.

Statement

An existential global tuple for each source and a local conclusion for every tuple with the same pin predicate give an integral tame unramified system and a nonzero inertia value for its very same cocycle.

Assumptions

  • A global tuple exists for every eligible source.
  • The local assertion applies to every tuple satisfying the same pin predicate.

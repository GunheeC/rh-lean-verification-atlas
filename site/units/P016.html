P016 · Zero-freeness from host existence and connectedness

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

A connectedness implication and the existence of suitable hosts on power windows for each designated primitive character imply half-plane nonvanishing for that class. The same window exponent must be greater than one throughout the setup.

Statement

Let $\lambda>1$. Assume TopG and HostExW$(\lambda,G_\psi)$ for every $\psi\in\mathcal P$. Then $L(s,\psi)\ne0$ for every $\psi\in\mathcal P$ and $\Re s>1/2$.

Assumptions

  • Fix $\lambda>1$ and assume the connected-family assertion TopG.
  • Every primitive character request $G_\psi$ admits hosts on windows with this same exponent $\lambda$.

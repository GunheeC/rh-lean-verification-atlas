Recording a decision

Keep the original report and its scope. Check new source pins before changing the unit YAML. Record a correction or unresolved disagreement in the relevant review or question and retain both sides' locators. A name match supplies navigation. A positive whole-unit grade needs evidence for every principal statement in that unit. An AI-written report cannot fill the named-human field.

After an accepted edit, regenerate the pages, declaration lookup and dashboard with python scripts/refresh_round4.py. Run python scripts/validate.py from the atlas root. Changes to public claims, grades or source editions belong in the change log. The citation file cites the atlas; mathematical claims should additionally cite their primary declarations and, when used, the outside author's edition.

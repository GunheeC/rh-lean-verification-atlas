# Open questions by track

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

[Reader-reported gaps, errors and resolutions](disputes.md)

Each track offers three specific questions. A response can document a calculation, compare two sets of hypotheses or locate an unresolved step. Start with the unit linked beside the question.

| Track | What to record |
|---|---|
| [Analytic number theory](analytic.md) | A table of quantifiers and constants next to the relevant transform or sum. |
| [Arakelov geometry and geometry of numbers](arakelov.md) | One numerical determinant calculation and a list of quantities which vary in the family. |
| [Theta correspondence and automorphic representations of unitary groups](theta.md) | The period, measure, test vector and normalization on both sides of the identity. |
| [Galois representations, automorphy lifting, Iwasawa theory and Euler systems](galois.md) | The weight, denominator, prime and field dependencies of each bound you use. |
| [Local p-adic theory](local.md) | The coefficient ring, valuation and integral lattice before and after the comparison. |
| [Algebraic K-theory and cohomology of arithmetic groups](ktheory.md) | The coefficient group, excluded primes and explicit upper bound at each step. |
| [Formalization and reproducibility](formal.md) | A replayable command or calculation, the input digest and the observed result. |

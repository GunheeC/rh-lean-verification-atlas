## Statement

Assume the one-field open-image record with field $\mathcal R$, the isobaric base-change assertion W02, and the Galois row for local parameters satisfying `IsRecT`. For each primitive character, each $0<\varepsilon<1/52$ and each admissible page function, the window $V$ of [P013](P013.md) holds. In particular a single $[Y,Y^2]$ works for all prescribed fields, all local data, and every finite set of primes, with twist cutoff $\lfloor x^{401}\rfloor$ and bound $\exp(x^\varepsilon/2)$.

## Assumptions

- The head takes the open-image record, isobaric base change and the Galois row separately. The open-image field is never projected by the adapters on this route. `UpperTheory.One.Join.automorphic_window_of_inputs` (`Development/AutomorphicArithmetic/AutomorphicVarieties/ModularityArgument/ThresholdArguments/DenseThresholdCases/TopMainZj.lean:71–74`).
- Test the window on a primitive character, an allowed exponent and an admissible page function.

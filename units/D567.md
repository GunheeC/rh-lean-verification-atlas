# D567 · The per-unit lattice error and the arithmetic bracket

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

At a sufficiently large scale satisfying the error windows, each unit's lattice error is bounded by the common arithmetic error bracket times a stated power of the scale. Thus a single bracket can be used across the units.

## Statement

If the listed error windows hold and x^epsilon dominates log x and the fixed largeness constant, the per-unit error ErrX5at is bounded by x^(CErr·epsilon) times ErrText for every u.

$$
\mathrm{ErrX5at}(D,C,X'',u)\le x^{C_{\rm Err}(C)\varepsilon}\,\mathrm{ErrText}(D).
$$

## Assumptions

- Fix finite index and nonempty word-fibre data, the arithmetic constants and one unit.
- The error windows and large-scale conditions both hold for these data.

# P031 · One cyclotomic generator for every layer

AI-written, AI cross-reviewed; no human sign-off; not a claim that RH is proved

One cyclotomic generator gives a cokernel formula for the localization-kernel length across every permitted layer and positive twist. Fixing that generator allows the layer index to vary while keeping the action being measured identifiable.

## Statement

Let $\ell$ be prime and let $L_0$ contain a primitive $\ell$-th root if $\ell$ is odd, or a primitive fourth root if $\ell=2$. Write $c_0$ for the largest $c$ such that $L_0$ contains a primitive $\ell^c$-th root. There exists $\gamma\in G_{L_0}$ whose cyclotomic image topologically generates the image and satisfies $v_\ell(\chi(\gamma)-1)=c_0$. The base contains a primitive $\ell^{c_0}$-th root. For every $E\ge1$, every $m\ge0$, and every degree-$\ell^m$ cyclotomic layer $L_m/L_0$,

$$
\operatorname{shaInv}(L_m,\ell,E)= \operatorname{length}_{\mathbb Z_\ell} \operatorname{coker}\bigl(x_{\mathrm{Tw}}(E,\gamma)^{\ell^m}-1\bigr).
$$

Here $x_{\mathrm{Tw}}$ is the twisted action on the dual of the infinite-layer character module with the specified local conditions.

## Assumptions

- Fix a prime $\ell$ and a number field containing a primitive $\ell$-th root when $\ell$ is odd, or a primitive fourth root at two.
- Use its maximal root-of-unity exponent and the corresponding tower.

## Statement

An existential global tuple for each source and a local conclusion for every tuple with the same pin predicate give an integral tame unramified system and a nonzero inertia value for its very same cocycle.

## Assumptions

- A global tuple exists for every eligible source.
- The local assertion applies to every tuple satisfying the same pin predicate.
